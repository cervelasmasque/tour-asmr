# Tour ASMR (V1)
Jeu 2D Godot 4.3, tablette Android.

- Flèches gauche/droite + bouton orange SAUT (clavier : flèches + espace pour tester).
- Ramasse les squishies : la tour monte. Plus haut = plus rare (Beurre tout en haut).
- Tomber = "Plouf ! On remonte", jamais de game over.
- Photos Lego : dépose-les dans le dossier `lego/` (png, jpg, webp). Un trophée tous les 20 étages.

## Obtenir l'APK
1. Crée un dépôt GitHub et envoie-y ce dossier.
2. Onglet Actions > "Compiler l'APK" > Run workflow.
3. Télécharge l'artefact `tour-asmr-apk`.
